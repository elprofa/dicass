# Images

Placez vos images ici : `src/assets/img`

- Référence en HTML/Angular : `<img src="assets/img/nom-image.png" alt="...">`
- Pour des images optimisées en production, utilisez les assets via l'Angular CLI (déjà inclus dans `src/assets`).

Fichier de placeholder : `placeholder.svg` (exemple d'utilisation).
